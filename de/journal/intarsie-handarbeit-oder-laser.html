Handgeschnittene Intarsie oder Holzkunst aus dem Laser? So erkennen Sie den Unterschied

Von Sasun Sargsyan · 25. November 2026 · 3 Min. Lesezeit

Wer online nach einem Porträt aus Holz sucht, findet Tausende — in jeder Preislage. Die meisten werden maschinell gefertigt, und die Fotos verraten es selten. Dieser Ratgeber erklärt die vier wichtigsten Arten von „Holzkunst“, wie Sie jede erkennen und was Sie vor einem Kauf oder Auftrag fragen sollten.

Vier Arten von Holzkunst

1. Lasergraviert

Ein Laser brennt das Bild in die Oberfläche einer einzigen Platte, so wie ein Drucker Punkte setzt. Das Ergebnis ist einfarbig, von hellem Beige bis Schwarz, und die Maserung einer einzigen Platte läuft geradlinig durch das ganze Bild.

2. Auf Holz gedruckt

Eine Fotografie wird mit Tinte, meist UV-gehärtet, auf eine Holzplatte gedruckt. Das Bild kann farbig und sehr detailreich sein, aber es liegt auf dem Holz, statt aus ihm zu bestehen.

3. Lasergeschnittene Intarsie

Echte Furnierteile werden von einem Laser nach einer digitalen Datei geschnitten und zusammengesetzt. Es ist echtes Holz, doch geschnitten hat eine Maschine — und dieselbe Datei lässt sich immer wieder schneiden.

4. Handgeschnittene Intarsie

Jedes Furnierteil wird von Hand mit Messer oder feiner Säge geschnitten und nach Augenmaß an seine Nachbarn angepasst. Jedes Teil ist einzigartig; nicht einmal sein Schöpfer kann es exakt wiederholen.

Fünf Merkmale, auf die Sie achten sollten

  1. Dunkle Konturen an jeder Kante. Ein Laser schneidet, indem er brennt; dabei bleibt um jedes Teil eine dünne, gleichmäßig breite verkohlte Linie zurück. Handgeschnittene Fugen sind sauber, die natürliche Farbe des Holzes reicht bis an die Fuge.
  2. Eine Platte, eine Maserung. Läuft die Maserung ununterbrochen über Gesicht, Hintergrund und Kleidung gleichermaßen, wurde das Bild auf eine einzige Platte graviert oder gedruckt.
  3. Die Maserung folgt der Form. Bei einer handgeschnittenen Intarsie wird die Maserung jedes Teils so gewählt, dass sie beschreibt, was es zeigt: entlang einer Haarsträhne, um eine Wange herum.
  4. Farben, die nur Holz haben kann. Ein Druck kann jede Farbe wiedergeben, auch Blau- und Grüntöne, die im Holz kaum vorkommen. Eine natürliche Intarsie trägt die Palette der Bäume.
  5. Eine Oberfläche, die man spürt. Aus der Nähe — und mit Erlaubnis — spürt man oft den feinen Unterschied in der Textur zwischen den Holzarten. Ein Druck ist vollkommen gleichförmig.

Ein Wort zu ehrlichen Ausnahmen

Nicht jede Technik, die Holz verändert, ist eine Abkürzung. Gefärbte Furniere und das Schattieren im heißen Sand, bei dem Teile in erhitztem Sand angesengt werden, um Volumen anzudeuten, sind traditionelle Methoden der Marketerie, und viele hervorragende Handwerker nutzen sie. Entscheidend ist nicht, ob eine Technik verwendet wird, sondern ob der Verkäufer es Ihnen klar sagt.

Fragen vor dem Auftrag

  • Wird jedes Teil von Hand geschnitten, oder per Laser oder CNC?
  • Aus wie vielen Teilen wird das Porträt bestehen?
  • Welche Holzarten werden verwendet?
  • Ist irgendeine Farbe gemalt, gefärbt, gebeizt oder gedruckt?
  • Sehe ich vor Beginn des Schneidens eine Vorschau und während der Arbeit Fotos vom Fortschritt?
  • Erhält das Werk ein signiertes Echtheitszertifikat?

Wer von Hand arbeitet, beantwortet jede dieser Fragen gern.
